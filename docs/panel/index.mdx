Aquadactyl is an open-source game server management panel built on Pterodactyl, featuring bundled Blueprint beta-2026-08 integration, production performance defaults, and managed update tooling.

<Callout type="warn">
  ## ⚠️ Warning: Automated Script Instability

**The automated installation script is currently experimental and highly unstable.**

Unexpected errors or dependency issues may occur during automated execution. For a stable, predictable, and recommended setup, please use the **[Manual Installation](/docs/getting-started/installing-the-panel)** guide instead.

</Callout>

## Supported Operating Systems [#supported-os]

The standalone deployment script supports the following Linux distributions:

| Operating System                            | Version                     | Supported |
| :------------------------------------------ | :-------------------------- | :-------: |
| **Ubuntu**                                  | `24.04 LTS (Noble Numbat)`  |    ✅     |
| **Ubuntu**                                  | `24.10 (Oracular Oriole)`   |    ✅     |
| **Ubuntu**                                  | `26.04+ LTS`                |    ✅     |
| **Debian**                                  | `12 (Bookworm)`             |    ✅     |
| **Debian**                                  | `13 (Trixie)`               |    ✅     |
| **Ubuntu**                                  | `22.04 LTS and earlier`     |    ❌     |
| **Debian**                                  | `11 (Bullseye) and earlier` |    ❌     |
| **RHEL / Rocky Linux / AlmaLinux / CentOS** | Any                         |    ❌     |

<Callout type="warn">
  **Deprecation Notice**: Older distributions such as Debian &le; 11 and Ubuntu
  &le; 22.04 are deprecated and unsupported. Please upgrade to Ubuntu 24.04+ or
  Debian 12+ before installing Aquadactyl.
</Callout>

## Automated Installation [#installation]

The installer script handles the entire installation process automatically, including installing packages, configuring MariaDB, setting up environment files, migrating database schemas, compiling frontend assets, configuring Nginx with SSL, and setting up the background queue worker.

Run the installer with a single command:

```bash title="Run automated installation"
curl -fsSL https://raw.githubusercontent.com/Aquadactyl/Installer/main/deploy.sh | sudo bash -s -- install
```

Or if `deploy.sh` is already downloaded locally on your server:

```bash title="Run local deployment script"
sudo bash deploy.sh install
```

During installation, follow the interactive prompts to enter your domain name, database credentials, and initial administrator account details.

## Next Steps [#next-steps]

Once the installation script completes:

1. Open your browser and navigate to your configured domain (e.g. `https://panel.example.com`) to log in with your administrator credentials.
2. [Install Wings](/docs/wings/installing-wings) to configure your server nodes and start hosting game servers.
3. Review [Additional Configuration](/docs/getting-started/additional-configuration) to customize Redis, email delivery, or install Blueprint extensions.
