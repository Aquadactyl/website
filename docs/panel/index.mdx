Aquadactyl combines the familiar Pterodactyl panel with bundled Blueprint,
branding controls, passkeys, connected accounts, languages, notifications and
optional server tools. See [Included features](/docs/panel/features).

## Current beta releases

| Component        | Version       | Release                                                                                  |
| ---------------- | ------------- | ---------------------------------------------------------------------------------------- |
| Aquadactyl Panel | `v1.1-beta.5` | [Notes and downloads](https://github.com/Aquadactyl/aquadactyl/releases/tag/v1.1-beta.5) |
| Manta            | `v1.1-beta.4` | [Notes and downloads](https://github.com/Aquadactyl/manta/releases/tag/v1.1-beta.4)      |
| Installer        | `v1.1-beta.2` | [Notes and tools](https://github.com/Aquadactyl/Installer/releases/tag/v1.1-beta.2)      |

The installer and panel have separate version numbers. Keep the installer tag
and the panel argument shown below; Manta is installed separately on each node.

## Install v1.1-beta.5

Use a dedicated Ubuntu 22.04/24.04/26.04 LTS or Debian 12/13 host:

```bash
git clone --depth 1 --branch v1.1-beta.2 https://github.com/Aquadactyl/Installer.git /opt/aquadactyl-installer
cd /opt/aquadactyl-installer
sudo bash deploy.sh install v1.1-beta.5
```

The installer fetches the exact panel release through Git and sets up the locked
dependencies, Blueprint, production build and services. Configure trusted HTTPS,
email and backups, then complete the administrator setup wizard.

Read the [full installation guide](/docs/panel/installing-the-panel) before
running it. v1.1-beta.5 is a prerelease: test your deployment and extensions first.

## Changes in these releases

Aquadactyl v1.1-beta.5 includes native PHP-FPM hardening and legacy Blueprint
frontend compatibility fixes. Manta v1.1-beta.4 hardens directory walks, archives
and MIME detection against special files. Update the panel and each daemon
separately; the Installer tools remain at v1.1-beta.2.

See the [panel upgrade steps](/docs/panel/updating-the-panel#native-fpm-hardening)
for existing native PHP-FPM configurations.
