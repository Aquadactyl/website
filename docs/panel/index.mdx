Aquadactyl combines the familiar Pterodactyl panel with bundled Blueprint,
branding controls, passkeys, connected accounts, languages, notifications and
optional server tools. See [Included features](/docs/panel/features).

## Install v1.0-beta

Use a dedicated Ubuntu 24.04/26.04 LTS or Debian 12/13 host:

```bash
git clone --depth 1 --branch v1.0-beta https://github.com/Aquadactyl/Installer.git /opt/aquadactyl-installer
cd /opt/aquadactyl-installer
sudo bash deploy.sh install v1.0-beta
```

The installer fetches the exact panel release through Git and sets up the locked
dependencies, Blueprint, production build and services. Configure trusted HTTPS,
email and backups, then complete the administrator setup wizard.

Read the [full installation guide](/docs/panel/installing-the-panel) before
running it. v1.0-beta is a prerelease: test your deployment and extensions first.
