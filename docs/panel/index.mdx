Aquadactyl combines the familiar Pterodactyl panel with bundled Blueprint,
branding controls, passkeys, connected accounts, languages, notifications and
optional server tools. See [Included features](/docs/panel/features).

## Current beta releases

Beta tags now advance the minor version: `v1.2-beta`, followed by `v1.3-beta`.

| Component        | Version       | Release                                                                                  |
| ---------------- | ------------- | ---------------------------------------------------------------------------------------- |
| Aquadactyl Panel | `v1.2-beta` | [Notes and downloads](https://github.com/Aquadactyl/aquadactyl/releases/tag/v1.2-beta) |
| Manta            | `v1.2-beta` | [Notes and downloads](https://github.com/Aquadactyl/manta/releases/tag/v1.2-beta)      |
| Installer        | `v1.3-beta` | [Notes and tools](https://github.com/Aquadactyl/Installer/releases/tag/v1.3-beta)      |

The installer and panel have separate version numbers. Keep the installer tag
and the panel argument shown below; Manta is installed separately on each node.

## Install v1.2-beta

Use a dedicated Ubuntu 22.04/24.04/26.04 LTS or Debian 12/13 host:

```bash
git clone --depth 1 --branch v1.3-beta https://github.com/Aquadactyl/Installer.git /opt/aquadactyl-installer
cd /opt/aquadactyl-installer
sudo bash deploy.sh install v1.2-beta
```

The installer fetches the exact panel release through Git and sets up the locked
dependencies, Blueprint, production build and services. Configure trusted HTTPS,
email and backups, then complete the administrator setup wizard.

Read the [full installation guide](/docs/panel/installing-the-panel) before
running it. v1.2-beta is a prerelease: test your deployment and extensions first.

## Changes in these releases

Aquadactyl v1.2-beta fixes Blueprint backend installation failures and separates
Manta/Wings update feeds, notes and beta comparisons. Manta v1.2-beta identifies
itself explicitly in its system API. The panel also recognizes older Manta betas
such as 1.1-beta.3. Installer v1.3-beta targets this panel release by default and
fixes the Blueprint inventory parsing error that blocked updates with addons.

See the [panel upgrade steps](/docs/panel/updating-the-panel#native-fpm-hardening)
for existing native PHP-FPM configurations.
