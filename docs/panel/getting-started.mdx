Aquadactyl is an open-source game management panel built on Pterodactyl with Blueprint integrated out of the box.

We offer two installation methods:

- **[Script Install (Only Panel)](#script-install)**: Fast, automated setup for deploying just the web panel.
- **[Standalone Install (Both Panel & Wings)](#standalone-install)**: Complete manual guide to run both the panel and the Wings daemon on a single server.

---

## System Requirements [#requirements]

Before starting, ensure your server meets the following requirements:

| Component            | Minimum / Supported Specification                                                                         |
| :------------------- | :-------------------------------------------------------------------------------------------------------- |
| **Operating System** | Ubuntu 22.04 / 24.04 LTS or Debian 11 / 12                                                                |
| **PHP**              | **PHP 8.5** (recommended) or **PHP 8.4** with PHP-FPM _(PHP 8.2 and 8.3 are unsupported)_                 |
| **PHP Extensions**   | `bcmath`, `curl`, `gd`, `mbstring`, `pdo_mysql`, `posix`, `xml`, `zip`                                    |
| **Node.js & pnpm**   | **Node.js >= 22.13** and **pnpm 12.10.1** (pinned)                                                        |
| **Composer**         | Composer 2                                                                                                |
| **Database & Cache** | MariaDB 10.11+ / MySQL 8.0+ and Redis 6+                                                                  |
| **System Tools**     | `rsync`, `util-linux` (`flock`, `runuser`), `zip`, `unzip`, `git`, `curl`, `mariadb-client` / `mysqldump` |
| **Hardware**         | 2+ CPU Cores, 2 GB RAM (4+ GB recommended for standalone hosting with Wings), 20+ GB SSD/NVMe             |

## Method 1: Script Install (Only Panel) [#script-install]

Aquadactyl includes a managed installation script (`scripts/panel-install.sh`) that automates dependency verification, environment initialization, database migrations, Blueprint bundling, and production asset compilation.

### What `panel-install.sh` Does

1. **Preflight checks**: Validates root/sudo privileges, required tools, PHP 8.4/8.5, Node 22.13+, and pnpm 12.10.1.
2. **Dependency installation**: Runs `composer install --no-dev --optimize-autoloader` and `pnpm install --frozen-lockfile` using committed lockfiles.
3. **Application secrets**: Automatically generates `APP_KEY` and `HASHIDS_SALT` in `.env` if not already present.
4. **Maintenance mode**: Enables maintenance mode (`artisan down --retry=60`) during migration.
5. **Database migrations**: Executes `artisan migrate --force` and runs `BlueprintSeeder` to prepare the database.
6. **Bundled Blueprint setup**: Runs Blueprint's internal initializer without upstream prompts, sets up CLI links, and builds metadata caches.
7. **Frontend compilation**: Builds production frontend bundles via `pnpm run build:production`.
8. **Permissions & caching**: Applies strict security permissions (code owned by `root:www-data`, only `storage/` and `bootstrap/cache/` writable by `www-data`), caches config/routes/views, and reloads PHP-FPM.
9. **Go live**: Disables maintenance mode and puts the panel online.

### 1. Install System Packages & Node/pnpm

On Ubuntu/Debian:

```bash title="Install core prerequisites"
sudo apt update && sudo apt install -y software-properties-common curl apt-transport-https ca-certificates gnupg lsb-release

# Add PHP PPA repository
sudo LC_ALL=C.UTF-8 add-apt-repository -y ppa:ondrej/php
sudo apt update

# Install PHP 8.5 with FPM and extensions
sudo apt install -y php8.5 php8.5-cli php8.5-fpm php8.5-gd php8.5-mysql php8.5-mbstring \
  php8.5-bcmath php8.5-xml php8.5-curl php8.5-zip php8.5-posix \
  mariadb-server mariadb-client nginx redis-server git tar unzip rsync util-linux

# Install Composer 2
curl -sS https://getcomposer.org/installer | sudo php -- --install-dir=/usr/local/bin --filename=composer

# Install Node.js 22 and pinned pnpm 12.10.1
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install --global pnpm@12.10.1
```

### 2. Configure Database

```bash title="Create database and user"
sudo mariadb -u root
```

```sql
CREATE DATABASE aquadactyl;
CREATE USER 'aquadactyl'@'127.0.0.1' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON aquadactyl.* TO 'aquadactyl'@'127.0.0.1' WITH GRANT OPTION;
FLUSH PRIVILEGES;
EXIT;
```

### 3. Download Aquadactyl & Configure Environment

```bash title="Prepare panel directory"
sudo mkdir -p /var/www/aquadactyl
cd /var/www/aquadactyl
sudo git clone https://github.com/Aquadactyl/aquadactyl.git .

sudo cp .env.example .env
sudo chmod 640 .env
sudo nano .env
```

Configure your domain and credentials:

```ini title="/var/www/aquadactyl/.env"
APP_URL=https://panel.yourdomain.com
DB_HOST=127.0.0.1
DB_DATABASE=aquadactyl
DB_USERNAME=aquadactyl
DB_PASSWORD=your_secure_password
CACHE_DRIVER=redis
SESSION_DRIVER=redis
QUEUE_CONNECTION=redis
```

### 4. Run `panel-install.sh`

```bash title="Run automated panel installer"
sudo bash scripts/panel-install.sh
```

### 5. Create Initial Administrator

For a fresh empty panel, seed base nests and create your administrative account:

```bash title="Seed default nests and create admin"
sudo -u www-data php artisan db:seed --class=DatabaseSeeder --force
sudo -u www-data php artisan p:user:make
```

### 6. Configure Nginx and Queue Worker

Complete the setup by installing the pre-configured Nginx site and systemd queue worker:

```bash title="Install webserver and queue service"
# Nginx site configuration
sudo cp deploy/nginx/panel.conf /etc/nginx/sites-available/aquadactyl.conf
sudo ln -s /etc/nginx/sites-available/aquadactyl.conf /etc/nginx/sites-enabled/
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d panel.yourdomain.com
sudo nginx -t && sudo systemctl reload nginx

# Background queue worker
sudo cp deploy/systemd/pteroq.service /etc/systemd/system/pteroq.service
sudo systemctl daemon-reload
sudo systemctl enable --now pteroq.service

# Scheduler cron
echo "* * * * * www-data cd /var/www/aquadactyl && /usr/bin/php artisan schedule:run >> /dev/null 2>&1" | sudo tee /etc/cron.d/aquadactyl
```

## Method 2: Standalone Install (Both Panel & Wings) [#standalone-install]

If you want to host **both the Aquadactyl Panel and Wings game daemon on the same server**, follow this standalone procedure.

### Step 1: Install System Dependencies & Docker

Install PHP 8.5, database, Redis, web server, and Docker:

```bash title="Install all packages"
sudo apt update && sudo apt install -y software-properties-common curl apt-transport-https ca-certificates gnupg lsb-release

# Add PHP PPA
sudo LC_ALL=C.UTF-8 add-apt-repository -y ppa:ondrej/php
sudo apt update

# PHP 8.5 & services
sudo apt install -y php8.5 php8.5-cli php8.5-fpm php8.5-gd php8.5-mysql php8.5-mbstring \
  php8.5-bcmath php8.5-xml php8.5-curl php8.5-zip \
  mariadb-server mariadb-client nginx redis-server git tar unzip rsync util-linux certbot python3-certbot-nginx

# Composer 2
curl -sS https://getcomposer.org/installer | sudo php -- --install-dir=/usr/local/bin --filename=composer

# Node.js 22 & pnpm 12.10.1
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install --global pnpm@12.10.1

# Docker CE
curl -sSL https://get.docker.com/ | CHANNEL=stable bash
sudo systemctl enable --now docker
```

Enable Linux swap accounting for Docker memory enforcement:

```bash title="/etc/default/grub"
# Ensure swapaccount=1 is present in GRUB_CMDLINE_LINUX_DEFAULT
sudo sed -i 's/GRUB_CMDLINE_LINUX_DEFAULT="/GRUB_CMDLINE_LINUX_DEFAULT="swapaccount=1 /' /etc/default/grub
sudo update-grub
```

### Step 2: Database Setup

```bash title="Setup MariaDB"
sudo mariadb -u root
```

```sql
CREATE DATABASE aquadactyl;
CREATE USER 'aquadactyl'@'127.0.0.1' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON aquadactyl.* TO 'aquadactyl'@'127.0.0.1' WITH GRANT OPTION;
FLUSH PRIVILEGES;
EXIT;
```

### Step 3: Install Panel with `panel-install.sh`

```bash title="Deploy Aquadactyl Panel"
sudo mkdir -p /var/www/aquadactyl
cd /var/www/aquadactyl
sudo git clone https://github.com/Aquadactyl/aquadactyl.git .

sudo cp .env.example .env
sudo chmod 640 .env
sudo nano .env
```

Set your domain and database credentials in `.env`, then run the installer:

```bash title="Execute panel installer"
sudo bash scripts/panel-install.sh

# Seed nests & make administrator
sudo -u www-data php artisan db:seed --class=DatabaseSeeder --force
sudo -u www-data php artisan p:user:make
```

### Step 4: Webserver, Queue & Cron Setup

```bash title="Configure Nginx, systemd queue, and cron"
# Install Nginx vhost
sudo cp deploy/nginx/panel.conf /etc/nginx/sites-available/aquadactyl.conf
sudo ln -s /etc/nginx/sites-available/aquadactyl.conf /etc/nginx/sites-enabled/
sudo certbot --nginx -d panel.yourdomain.com
sudo nginx -t && sudo systemctl reload nginx

# Install queue service
sudo cp deploy/systemd/pteroq.service /etc/systemd/system/pteroq.service
sudo systemctl daemon-reload
sudo systemctl enable --now pteroq.service

# Setup cron scheduler
echo "* * * * * www-data cd /var/www/aquadactyl && /usr/bin/php artisan schedule:run >> /dev/null 2>&1" | sudo tee /etc/cron.d/aquadactyl
```

### Step 5: Install & Configure Wings on the Same Host

Now install the Wings daemon:

```bash title="Install Wings binary"
sudo mkdir -p /etc/pterodactyl /var/lib/pterodactyl/volumes
curl -L -o /usr/local/bin/wings "https://github.com/pterodactyl/wings/releases/latest/download/wings_linux_amd64"
sudo chmod u+x /usr/local/bin/wings
```

1. Navigate to your panel in your browser at `https://panel.yourdomain.com`.
2. Go to **Admin Control** -> **Locations** and create a Location (e.g. `Local`).
3. Go to **Nodes** -> **Create New**:
   - **Name**: `Local Node`
   - **Location**: `Local`
   - **FQDN**: `node.yourdomain.com` (or your server's domain/IP)
   - **Daemon Port**: `8080`
   - **Daemon SFTP Port**: `2022`
   - Enter your RAM and Disk allocation limits.
4. Click **Create Node**, open the **Configuration** tab, and copy the YAML block.
5. Paste it into `/etc/pterodactyl/config.yml`:

```bash title="Create node config"
sudo nano /etc/pterodactyl/config.yml
```

6. Configure and enable the Wings systemd service:

```bash title="Start Wings service"
sudo tee /etc/systemd/system/wings.service > /dev/null << 'EOF'
[Unit]
Description=Wings Daemon
After=docker.service
Requires=docker.service
PartOf=docker.service

[Service]
User=root
WorkingDirectory=/etc/pterodactyl
LimitNOFILE=4096
PIDFile=/var/run/wings/daemon.pid
ExecStart=/usr/local/bin/wings
Restart=on-failure
StartLimitInterval=180
StartLimitBurst=30
RestartSec=5s

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now wings
```

Verify Wings is active:

```bash
sudo systemctl status wings
```

Your node in the Aquadactyl admin area will display a green heartbeat indicating that both the Panel and Wings are running on your server!
