## POST `/api/client/servers/{server}/backups/{backup}/restore`

Handles restoring a backup by making a request to the Wings instance telling it to begin the process of finding (or downloading) the backup and unpacking it over the server files. If the "truncate" flag is passed through in this request then all the files that currently exist on the server will be deleted before restoring. Otherwise, the archive will simply be unpacked over the existing files.

**Access:** Client API key or authenticated panel session; `backup.restore`.

**Source:** [Route](https://github.com/Aquadactyl/aquadactyl/blob/2bfd6ae2a30c8152b34b53c53562773a973ae901/routes/api-client.php) · [Controller](https://github.com/Aquadactyl/aquadactyl/blob/2bfd6ae2a30c8152b34b53c53562773a973ae901/app/Http/Controllers/Api/Client/Servers/BackupController.php) · [Request validation](https://github.com/Aquadactyl/aquadactyl/blob/2bfd6ae2a30c8152b34b53c53562773a973ae901/app/Http/Requests/Api/Client/Servers/Backups/RestoreBackupRequest.php)

    throw new BadRequestHttpException('This server is not currently in a state that allows for a backup to be restored.');
}

    throw new BadRequestHttpException('This backup cannot be restored at this time: not completed or failed.');

    ->subject($backup)
    ->property(['name' => $backup->name, 'truncate' => $request->input('truncate')]);

        $url = $this->downloadLinkService->handle($backup, $request->user());
    }

    $server->update(['status' => Server::STATUS_RESTORING_BACKUP]);

    $this->daemonRepository->setServer($server)->restore($backup, $url ?? null, $request->input('truncate'));
});

return new JsonResponse([], JsonResponse::HTTP_NO_CONTENT);
