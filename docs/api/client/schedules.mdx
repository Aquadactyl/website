## POST `/api/client/servers/{server}/schedules/{schedule}/execute`

Executes a given schedule immediately rather than waiting on it's normally scheduled time to pass. This does not care about the schedule state. Tasks are not checked against their action permissions here. They cannot be created or modified without that permission, and anyone reaching this endpoint can already run them by re-pointing the cron expression.

**Access:** Client API key or authenticated panel session; `schedule.update`.

Delete a given task for a schedule. If there are subsequent tasks stored in the database for this schedule their sequence IDs are decremented properly.

**Access:** Client API key or authenticated panel session.

**Source:** [Route](https://github.com/Aquadactyl/aquadactyl/blob/2bfd6ae2a30c8152b34b53c53562773a973ae901/routes/api-client.php) · [Controller](https://github.com/Aquadactyl/aquadactyl/blob/2bfd6ae2a30c8152b34b53c53562773a973ae901/app/Http/Controllers/Api/Client/Servers/ScheduleTaskController.php) · [Request validation](https://github.com/Aquadactyl/aquadactyl/blob/2bfd6ae2a30c8152b34b53c53562773a973ae901/app/Http/Requests/Api/Client/ClientApiRequest.php)

Validation is inherited from [ApplicationApiRequest.php](https://github.com/Aquadactyl/aquadactyl/blob/2bfd6ae2a30c8152b34b53c53562773a973ae901/app/Http/Requests/Api/Application/ApplicationApiRequest.php).

**Path parameters:** `server`, `schedule`, `task`. See [identifiers](/docs/api/authentication#identifiers).
