## Node authentication

Wings calls the panel using `Authorization: Bearer TOKEN_ID.TOKEN_SECRET`, matching the node's configured daemon token. This is not a Client or Application API key. The middleware resolves the node and compares its decrypted secret using a constant-time check. Missing credentials return 401, malformed credentials return 400, and a rejected credential returns 403. Scope callbacks to resources belonging to that node.

These are internal Wings-to-panel callbacks. Prefer the Client or Application API for user integrations. A 204 callback result has no response body. See [node authentication middleware](https://github.com/Aquadactyl/aquadactyl/blob/2bfd6ae2a30c8152b34b53c53562773a973ae901/app/Http/Middleware/Api/Daemon/DaemonAuthenticate.php).

    if ($adapter instanceof S3Filesystem) {
        $this->completeMultipartUpload($model, $adapter, $successful, $request->input('parts'));
    }
});

return new JsonResponse([], JsonResponse::HTTP_NO_CONTENT);

## POST `/api/remote/backups/{backup}/restore`

Handles toggling the restoration status of a server. The server status field should be set back to null, even if the restoration failed. This is not an unsolvable state for the server, and the user can keep trying to restore, or just use the reinstall button. The only thing the successful field does is update the entry value for the audit logs table tracking for this restoration.

**Access:** Wings node bearer credentials; internal callback.

**Source:** [Route](https://github.com/Aquadactyl/aquadactyl/blob/2bfd6ae2a30c8152b34b53c53562773a973ae901/routes/api-remote.php) · [Controller](https://github.com/Aquadactyl/aquadactyl/blob/2bfd6ae2a30c8152b34b53c53562773a973ae901/app/Http/Controllers/Api/Remote/Backups/BackupStatusController.php)

**Path parameters:** `backup`. See [identifiers](/docs/api/authentication#identifiers).
